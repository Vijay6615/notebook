Practical 1

Directories banana, subdirectory banana, rename/move/copy aur directory delete karna. 

Step 1 – Terminal open karein
RHEL desktop par Ctrl + Alt + T press karein.
Step 2 – 3 directories banayein
mkdir tyit1 tyit2 tyit3
Use: Ek command se teen folders create honge. Expected: Koi output nahi; prompt wapas aa jayega.
Step 3 – tyit2 ke andar linux folder banayein
mkdir tyit2/linux
Use: tyit2 ke andar subdirectory create hogi. Expected: Koi output nahi.
Step 4 – tyit3 ka naam tyit4 karein
mv tyit3 tyit4
Use: mv command directory ka naam change karegi. Expected: Koi output nahi.
Step 5 – pqr file banayein
touch pqr
Use: Empty file create hogi. Expected: Koi output nahi.
Step 6 – pqr ko tyit1 mein move karein
mv pqr tyit1/
Use: File tyit1 folder ke andar chali jayegi. Expected: Koi output nahi.
Step 7 – pqr ki copy xyz naam se banayein
cp tyit1/pqr xyz
Use: Current directory mein xyz naam ki copy banegi. Expected: Koi output nahi.
Step 8 – tyit4 delete karein
rmdir tyit4
Use: Empty directory delete hogi. Agar directory empty na ho, tab rm -r tyit4 use karein. Expected: Koi output nahi.
Step 9 – Result verify karein
ls
ls tyit1
ls tyit2
Expected output (example):
First ls: tyit1  tyit2  xyz
ls tyit1: pqr
ls tyit2: linux

Practical 1

Do users aur do groups create karna, users ko secondary groups mein add karna aur assignment check karna. 

Step 1 – Do groups banayein
sudo groupadd group1
sudo groupadd group2
Use: group1 aur group2 create honge. Expected: Koi output nahi.
Step 2 – Do users banayein
sudo useradd student1
sudo useradd student2
Use: Dono local user accounts create honge. Expected: Koi output nahi.
Step 3 – Users ke passwords set karein
sudo passwd student1
sudo passwd student2
Use: Dono users ke liye password set karein. Password type karte waqt screen par characters nahi dikhte; ye normal hai. Expected: Retype password ke baad “all authentication tokens updated successfully” message.
Step 4 – student1 ko group2 mein add karein
sudo usermod -aG group2 student1
Use: student1 ko group2 mein add karta hai. -a zaroor lagayein, taaki existing supplementary groups remove na hon. Expected: Koi output nahi.
Step 5 – student2 ko group1 mein add karein
sudo usermod -aG group1 student2
Use: student2 ko group1 mein secondary group ke roop mein add karega. Expected: Koi output nahi.
Step 6 – Group assignments check karein
groups student1
groups student2
Expected output (example):
student1 : student1 group2
student2 : student2 group1
Output mein group1/group2 ka hona verify karein; exact primary-group details system ke hisaab se differ kar sakti hain.
Step 7 – Detailed verification (optional)
id student1
id student2

Practical 1

File create karke usme 7 lines likhna aur file-handling commands ka output check karna. 

Step 1 – File create karein
touch hello.txt
Use: hello.txt naam ki empty file banegi. Expected: Koi output nahi.
Step 2 – File mein 7 lines likhein
nano hello.txt
Nano editor khulega. Neeche ki 7 lines type karein:
Linux is an operating system
Linux is free
Linux is secure
Linux supports users
Linux uses commands
Linux manages files
Linux is powerful
Save karne ke liye Ctrl + O, Enter; phir Ctrl + X press karein.
Step 3 – File ka content dekhein
cat hello.txt
Expected output:
Linux is an operating system
Linux is free
Linux is secure
Linux supports users
Linux uses commands
Linux manages files
Linux is powerful
Step 4 – File ko reverse order mein dekhein
tac hello.txt
Expected output: Lines last se first order mein display hongi:
Linux is powerful
Linux manages files
Linux uses commands
Linux supports users
Linux is secure
Linux is free
Linux is an operating system
Step 5 – Starting ki 2 lines dekhein
head -n 2 hello.txt
Expected output:
Linux is an operating system
Linux is free
Step 6 – Last ki 3 lines dekhein
tail -n 3 hello.txt
Expected output:
Linux uses commands
Linux manages files
Linux is powerful
Step 7 – Lines, words aur bytes count karein
wc hello.txt
Expected output (is exact sample file ke liye):
7  23  138 hello.txt
Meaning: 7 = lines, 23 = words, 138 = bytes. File ko isi tarah save karein, last line ke baad Enter/newline ho.
Step 8 – Characters count karein
wc -m hello.txt
Expected output (same sample file):
138 hello.txt

Practical 1

Linux mein hard link aur soft (symbolic) link create karna aur unka use verify karna 

Step 1 – Terminal open karein

RHEL desktop par Ctrl + Alt + T press karein.

Step 2 – Original file create karein

Ek empty file create hogi.

touch original.txt

Expected output: Usually koi output nahi aayega.

Step 3 – File mein content add karein

File mein text write hoga.

echo "Welcome to Linux" > original.txt

Expected output: Usually koi output nahi aayega.

Step 4 – Hard link create karein

Original file ka hard link create hoga.

ln original.txt hardlink.txt

Expected output: Usually koi output nahi aayega.

Step 5 – Soft link create karein

Original file ka symbolic link create hoga.

ln -s original.txt softlink.txt

Expected output: Usually koi output nahi aayega.

Step 6 – Links verify karein

Original aur hard link ka inode number same hona chahiye. Soft link ke output mein -> original.txt dikhna chahiye.

ls -li

Expected output: Example (numbers, owner aur permissions system ke hisaab se alag ho sakte hain):
original.txt aur hardlink.txt ke inode numbers same honge.
softlink.txt -> original.txt

Step 7 – Hard link ka content dekhein

cat hardlink.txt

Expected output: Welcome to Linux

Step 8 – Soft link ka content dekhein

cat softlink.txt

Expected output: Welcome to Linux

Viva: Hard link original file ke same inode ko share karta hai. Soft link (symbolic link) original file ke path ko point karta hai.

Practical 1

B Linux mein hostname set karna aur /etc/hosts ke through hostname resolution verify karna. 


            Step 1 – Current hostname check karein

hostname

Expected output: Aapke RHEL system ka current hostname display hoga.

Step 2 – Hostname set karein

Administrator permission ke saath hostname ko linuxlab set karein.

sudo hostnamectl set-hostname linuxlab

Expected output: Usually koi output nahi aayega. Agar sudo password maange toh apna user password enter karein.

Step 3 – Hosts file open karein

File ke end mein ye mapping add karein: 127.0.0.1 linuxlab

sudo nano /etc/hosts

Expected output: Save: Ctrl + O, phir Enter. Exit: Ctrl + X.

127.0.0.1   linuxlab

Step 4 – Hostname verify karein

hostname

Expected output: linuxlab

Step 5 – Hostname resolution check karein

getent command system name-service configuration ke through hostname resolve karke dikhata hai.

getent hosts linuxlab

Expected output: 127.0.0.1 linuxlab (format/spacing alag ho sakti hai).
